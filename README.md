## 01. 👨‍💻 About Me

I'm **Divyanshu Verma**, a developer and technology enthusiast interested in building modern web applications, e-commerce platforms, AI-powered products, and business automation solutions.

My work spans frontend development, backend integrations, database-driven applications, user interface engineering, and intelligent automation.

Through independent projects and **DEADCODE LABS**, I explore how thoughtful engineering, good design, and practical AI can solve real-world problems.

- 💻 **Software Engineering** — Responsive interfaces and maintainable application structures.
- 🌐 **Full-Stack Development** — Connecting frontend experiences with APIs, databases, and backend services.

- 🛍️ **E-commerce Engineering** — Shopify and WordPress development and customization.
- 🎨 **Product Design** — Clean interfaces with attention to usability, accessibility, and consistency.
- ⚙️ **Problem Solving** — Debugging application issues and improving workflows.
- 🚀 **Product Mindset** — Building around real requirements instead of adding technology without a purpose.

**Currently open to:** Software development opportunities, freelance projects, full-stack applications, AI and automation projects, e-commerce development, and open-source collaboration.
